# Diplomas & Certificates 🎓📜

This repository stores my diplomas, course certificates, and professional badges in a single, organized place. It’s intended as a digital portfolio and an easy-to-share archive of my educational achievements.

Overview
- Purpose: Keep scanned diplomas and course certificates organized, discoverable, and ready for sharing or verification. 🔍
- Contents: Scans (PDF / PNG / JPG) and optional metadata (JSON / YAML) describing each certificate. 🗂️
